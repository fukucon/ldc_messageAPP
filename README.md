# LDC Chat (GAS版 Googleチャット風アプリ)

Google Apps Script + スプレッドシートで動く、モバイルファーストの最小チャットアプリです。

## 構成

| ファイル | 役割 |
| --- | --- |
| `setup.gs` | シート生成・カラム設定（初回のみ手動実行） |
| `code.gs` | Webアプリのメイン動作（送受信・ルーム管理） |
| `index.html` | モバイルファーストのチャットUI |
| `appsscript.json` | マニフェスト（Webアプリ設定） |

## データ構造（スプレッドシート）

- **Rooms** シート: `roomId`, `name`, `createdAt`
- **Messages** シート: `messageId`, `roomId`, `user`, `text`, `createdAt`

## セットアップ手順

1. 対象スプレッドシートに紐づくApps Scriptプロジェクトを開く
   （`code.gs` 内の `SPREADSHEET_ID` が対象）。
2. 各ファイルをプロジェクトにコピーする。
3. エディタで `setup` 関数を一度だけ実行し、シートとヘッダーを生成する。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」で公開する。
5. 発行されたURLをスマホで開く。

## 機能（最小実装）

- ルームの一覧表示・新規作成
- ルーム内のメッセージ送受信
- 3秒ごとのポーリングによる簡易リアルタイム更新
- ログインユーザーのメールアドレスを送信者として記録
