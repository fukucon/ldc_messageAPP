# 就労規則チャットボット (GAS + Gemini)

就労規則をスプレッドシートに登録しておき、社員が質問すると就労規則の内容に基づいて
Gemini が回答するチャットボットです。Google Apps Script + Gemini API で動きます。

## メイン画面
Webアプリを開くと**就労規則チャットボット**が表示されます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `code.gs` | メイン動作（`doGet`・ボット回答・OCR・チャット） |
| `setup.gs` | シート生成・カラム設定 |
| `bot.html` | 就労規則チャットボットのUI（メイン画面） |
| `index.html` | 旧チャット画面（隠し機能・`?app=chat`） |
| `ocr.html` | PDF/画像OCR画面（隠し機能・`?app=ocr`） |
| `appsscript.json` | マニフェスト（Webアプリ設定） |

## セットアップ手順

1. スプレッドシートに紐づくApps Scriptプロジェクトに各ファイルをコピー。
2. `setupApiKey()` の `API_KEY` に Gemini API キーを貼り付けて1回実行（キーが保存される）。
   実行後は `API_KEY` をプレースホルダに戻してよい。
3. `setupBot()` を1回実行し、「就労規則」「質問ログ」シートを生成。
4. スプレッドシートの**「就労規則」シートのA2以降に就労規則の本文を貼り付け**。
5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で公開。
6. 発行されたURLを開くとチャットボットが表示される。

## 就労規則ボットの仕組み（方式1）

- 質問のたびに「就労規則」シートの全文＋質問を Gemini（gemini-2.5-flash）へ送信。
- 就労規則の範囲だけで回答し、記載が無い事項は「記載がありません」と返す。
- 質問と回答は「質問ログ」シートに自動記録。
- 回答の口調・方針は `code.gs` の `BOT_SYSTEM_INSTRUCTION` で調整可能。

## 隠し機能（URLで直接アクセス）

- `?app=chat` … 旧チャット（ルーム・メッセージ送受信）
- `?app=ocr` … PDF/画像のOCR

## データ構造（スプレッドシート）

- **就労規則**: A2以降に規則本文
- **質問ログ**: `日時`, `社員`, `質問`, `回答`
- **Rooms / Messages**: 旧チャット用
- **OCR結果**: OCR保存用
